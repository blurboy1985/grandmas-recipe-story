# Data model — finalized 27 October 2026

Implemented from Milestone A onward. One SQLite database plus private media
under `DATA_DIR`, outside `public/`. All IDs are app-generated UUIDs unless
stated. No user-controlled filesystem paths are stored or accepted; only
private relative paths generated by the server.

## Tables

| Table | Key columns / invariants |
| --- | --- |
| `recordings` | `id`, `relative_path` (server-generated, inside `DATA_DIR`), `photo_relative_path` nullable, `sha256` of actual bytes, `format='wav-pcm-mono'`, `duration_ms` (validated 60,000–300,000), `byte_size` (<=20 MB), `consent_at`, `created_at`. Photo is presentation, not evidence. |
| `jobs` | `id`, `recording_id` FK, `mode` (`sample`\|`live`), processing state (`uploaded`\|`transcribing`\|`transcript_ready`\|`extracting`\|`draft_ready`\|`failed`), `approved_transcript_version_id` nullable, `safe_error_code` nullable, timestamps. Server-only transitions per `ARCHITECTURE.md`. |
| `transcript_versions` | `id`, `recording_id` FK, `kind` (`original`\|`edited`), `text`, `segments_json` (ordered `[{id:"seg-01", text}]`, IDs assigned in code per version), `created_at`, `approved_at` nullable. Original is immutable; edits create new rows. |
| `recipe_versions` | `id`, `job_id` FK, `transcript_version_id` (approved version used), `input_hash`, `model`, `prompt_version`, `schema_version`, `output_json` (validated extraction, below), review state (`draft`\|`reviewed_with_unknowns`\|`confirmed`), safe usage metadata (token counts, latency, request id — no content), `created_at`. Never overwritten; regeneration inserts a new row. |
| `clarifications` | `id`, `recipe_version_id` FK, `question`, `related_field`, `source_segment_ids_json`, `answer` nullable, `answered_at` nullable, provenance (`model` question; `family` answer). Check: at most 3 rows per recipe version (enforced in code + trigger/constraint where practical). |
| `family_corrections` | `id`, `recipe_version_id` FK, `target_field`, `previous_value_json`, `corrected_value_json`, `created_at`. Kept apart from generated `output_json`, which is never mutated by corrections. |
| `model_cache` | `cache_key` PK, `kind` (`transcription`\|`extraction`), `state` (`running`\|`complete`\|`failed`), `result_ref`, `created_at`. Unique key is the dedup guard. |
| `tombstones` | `id`, `relative_path`, `created_at` — files pending deletion retry. |

Foreign keys on; deletes cascade from `recordings` -> `jobs` ->
`transcript_versions` / `recipe_versions` -> `clarifications` /
`family_corrections`. File deletion follows the transaction (see
`ARCHITECTURE.md` deletion/recovery).

## Cache keys (canonical)

- Transcription: `sha256(audio_bytes) + transcribe_model + options_version`.
- Extraction: `sha256(canonical_json(approved_transcript_segments, notes,
  clarification_answers)) + extract_model + prompt_version + schema_version`.
- Canonical JSON = sorted keys, stable segment order. Any edit changes the
  hash; refresh/save/print/reopen never create a key or a paid call.

## Extraction output JSON Schema

Flat, non-recursive, root object, no additional properties. Derived from the
single Zod schema via `z.toJSONSchema()`; the same Zod schema re-validates
responses, plus code checks for segment-ID membership, <=3 questions, and
quote verification. Unknown quantity is explicit `null`, never omitted.

```json
{
  "type": "object",
  "additionalProperties": false,
  "required": ["dish_name", "ingredients", "steps", "story", "clarifications"],
  "properties": {
    "dish_name": {
      "type": ["string", "null"],
      "description": "Null if the source never names the dish."
    },
    "ingredients": {
      "type": "array",
      "items": {
        "type": "object",
        "additionalProperties": false,
        "required": ["name", "quantity_text", "original_words", "source_segment_ids", "needs_confirmation"],
        "properties": {
          "name": { "type": "string", "minLength": 1 },
          "quantity_text": { "type": ["string", "null"] },
          "original_words": { "type": "string" },
          "source_segment_ids": { "type": "array", "minItems": 1, "items": { "type": "string", "pattern": "^seg-[0-9]{2,}$" } },
          "needs_confirmation": { "type": "boolean" }
        }
      }
    },
    "steps": {
      "type": "array",
      "items": {
        "type": "object",
        "additionalProperties": false,
        "required": ["instruction", "source_segment_ids", "needs_confirmation"],
        "properties": {
          "instruction": { "type": "string", "minLength": 1 },
          "source_segment_ids": { "type": "array", "minItems": 1, "items": { "type": "string", "pattern": "^seg-[0-9]{2,}$" } },
          "needs_confirmation": { "type": "boolean" }
        }
      }
    },
    "story": {
      "type": "object",
      "additionalProperties": false,
      "required": ["paraphrase", "source_segment_ids", "quotes"],
      "properties": {
        "paraphrase": { "type": "string", "description": "Empty string when the source has no story. Always displayed labelled as a paraphrase." },
        "source_segment_ids": { "type": "array", "items": { "type": "string", "pattern": "^seg-[0-9]{2,}$" } },
        "quotes": {
          "type": "array",
          "items": {
            "type": "object",
            "additionalProperties": false,
            "required": ["text", "source_segment_id"],
            "properties": {
              "text": { "type": "string", "minLength": 1 },
              "source_segment_id": { "type": "string", "pattern": "^seg-[0-9]{2,}$" }
            }
          }
        }
      }
    },
    "clarifications": {
      "type": "array",
      "maxItems": 3,
      "items": {
        "type": "object",
        "additionalProperties": false,
        "required": ["question", "related_field", "source_segment_ids"],
        "properties": {
          "question": { "type": "string", "minLength": 1 },
          "related_field": { "type": "string", "minLength": 1 },
          "source_segment_ids": { "type": "array", "items": { "type": "string", "pattern": "^seg-[0-9]{2,}$" } }
        }
      }
    }
  }
}
```

Code-level rules beyond the schema: every cited ID exists in the approved
transcript version; a quote's `text` equals its segment text verbatim;
`quantity_text: null` requires non-empty `original_words` and
`needs_confirmation: true`; no step may add times/temperatures absent from
its cited segments (semantic tests in Milestone B); empty story requires
`paraphrase: ""` and `quotes: []`.
